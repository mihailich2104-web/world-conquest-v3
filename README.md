# World Conquest

Пошаговая глобальная стратегия в духе Hearts of Iron IV на Python (Pygame-CE + pygame_gui).
Карта мира — реальные страны из Natural Earth 110m (границы подготавливает `tools/prepare_map.py`).
Играть можно за любую страну; есть встроенное обучение. Работает офлайн, сохранения — SQLite.
Сборка `.exe` (Windows) и бинарника (Linux) автоматизирована через GitHub Actions и управляется из Termux.

## Установка на ПК (запуск из исходников)
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python tools/prepare_map.py       # скачает Natural Earth → src/data/provinces.geojson
python tools/gen_countries.py     # создаст src/data/countries.json
python src/main.py
```
Без `provinces.geojson` игра запускается на запасной карте-сетке (для проверки) и пишет предупреждение в лог.
GeoPandas не нужен: карта читается напрямую как JSON. Готовый `src/data/provinces.geojson` уже лежит в проекте.

> ⚠️ Нужен именно **pygame-ce** (`pip install pygame-ce`), а не `pygame`: `pygame_gui` не работает с обычным pygame (ошибка `cannot import name 'DIRECTION_LTR'`). Если стоял `pygame` — сначала `pip uninstall pygame`.

## Сборка .exe локально
```bash
bash build_exe.sh          # Windows — из Git Bash
```
Результат: `dist/WorldConquest.exe` (Windows) или `dist/WorldConquest` (Linux).
По умолчанию GeoPandas в exe не упаковывается (он не нужен в рантайме и раздувает файл);
включить: `WC_BUNDLE_GEOPANDAS=1 bash build_exe.sh`.

## Сборка через GitHub Actions
1. Создайте репозиторий и запушьте проект — workflow `.github/workflows/build.yml` стартует на каждый push (или вручную: *Actions → Build EXE → Run workflow*).
2. После сборки скачайте артефакты `WorldConquest-Windows`, `WorldConquest-Linux`. Артефакт `world-data` содержит готовый `provinces.geojson`.

## Управление из Termux (пошагово)
1. `pkg install git gh python`
2. `gh auth login`
3. `git clone https://github.com/USER/world-conquest`
4. `cd world-conquest`
5. `git add . && git commit -m "update" && git push`
6. `gh run watch`  — следить за сборкой
7. `gh run download`  — скачать артефакты (.exe и Linux-бинарник)

Всё это же делает `./run_termux.sh build`. Запуск самой игры в Termux (`./run_termux.sh play`) требует termux-x11 и pygame и не гарантирован — основной сценарий для телефона: править код и собирать в облаке.

## Управление в игре
| Действие | Ввод |
|---|---|
| Сдвиг карты | ЛКМ + перетаскивание |
| Масштаб | колесо мыши |
| Выбор страны | клик по стране |
| Следующий ход (1 день) | Пробел / кнопка «След. ход» |
| Автоход | `A` / кнопка «Авто» |
| Режим карты (политический / идеологии) | `M` |
| Камера на свою страну | `C` |
| Быстрое сохранение / загрузка последнего | `F5` / `F9` |
| Меню (с автосохранением) | `Esc` |

Панели: **Страна** (строить фабрики/укрепления, налоги), **Дипломатия** (отношения, торговля, пакт, союз, война, мир),
**Исследования** (5 веток × 6 уровней, 2 слота), **Армия** (найм дивизий/кораблей/авиации, войны).

## Правила кратко
- 1 ход = 1 день. Порядок: экономика → производство → рекрутинг → исследования → бои → ИИ.
- Война: `power_атакующих = Σ(юниты·tech·мораль)`, `power_защитников = Σ(юниты·tech·мораль·укрепления)`; ежедневно счёт войны сдвигается в пользу сильнейшего. При счёте ±100 побеждает одна из сторон: страна проигравшего защитника **оккупируется целиком** (провинция = страна на карте 110m).
- Воевать можно с соседом (общая граница) или при флоте ≥ 3 кораблей. После мира — перемирие 30 дней.
- Победа: контроль ≥ 50% провинций мира. Поражение: оккупирована ваша страна.
- ИИ сам развивается, заключает соглашения и изредка нападает на более слабых соседей (агрессия — в настройках).

## Прохождение туториала
«Обучение» в главном меню → 6 шагов: 1) выбрать страну, 2) посмотреть на свою страну, 3) построить фабрику,
4) нанять дивизию, 5) объявить войну подсвеченному слабому соседу, 6) выиграть первый бой (Пробел). В обучении ИИ не нападает на вас.

## Что нового (версия с автоматическим временем и LAN)

- **Время**: дата идёт сама. Пробел — пауза/пуск, клавиши 1–5 или кнопки 1X/2X/4X/8X/16X, `+`/`-` — быстрее/медленнее,
  `.` или «+1 день» — шаг на день (на паузе). Один общий игровой цикл (`core/clock.py`), без таймеров.
- **Интерфейс**: сверху дата, скорость, казна, население, армия, стабильность; слева действия; в центре карта;
  справа сводка выбранной страны (население, экономика, армия, стабильность, отношения).
- **Экономика**: налоги, торговля, расходы на армию, производство; события (кризис, подъём, реформы, протесты,
  перевороты, учения, засуха, урожай, научный прорыв).
- **Технологии**: Экономика, Армия (пехота/танки/авиация/флот), Промышленность, Инфраструктура, Дипломатия — у каждой ветки
  реальные бонусы (доход, сила армии, производство, рост/резервы/снабжение, эффект дипломатии).
- **ИИ**: развивает экономику, строит армию и укрепления, ищет союзы, объявляет войны, просит мира,
  реагирует на агрессивных игроков, делает игроку предложения (принять/отклонить в «Дипломатии»).
- **LAN**: Мультиплеер → «Создать LAN игру» (показывает IP и порт) / «Подключиться к LAN» (ручной ввод IP:порт или
  автопоиск). Лобби со списком игроков, выбором страны на карте и готовностью. Хост авторитетен: клиент шлёт
  команды, хост проверяет и рассылает снимок мира (дата, скорость, паузa, страны, армии, войны, экономика).
  Порт по умолчанию 47800 (TCP), автопоиск — UDP 47801; разрешите их в брандмауэре Windows.
- Тесты: `python tests/test_core.py`, `test_tutorial.py`, `test_features.py`, `test_lan.py`, `test_smoke_ui.py`.


## Карта (реализм)

- Проекция Миллера, градусная сетка, мелководье у берегов, береговая линия, приглушённые цвета держав.
- Точные границы: в сборке (GitHub Actions) `tools/prepare_map.py --force` скачивает Natural Earth **50m**
  (при ошибке остаётся запасная 110m из проекта). Мелкие территории присоединяются к своему суверену.
- Столицы стоят на настоящих координатах (`src/data/capitals.json`): звезда — действующая столица,
  ромб цвета владельца — столица захваченной страны.
- Война: от столицы атакующего к столице защитника идёт маршрут; стрелка с числом дивизий показывает, где сейчас армия
  (граница пересекается при счёте 0, столица защитника достигается при +100). У защитника гарнизон на столице.
- Захват: страна целиком переходит к завоевателю — её границы стираются, территория сливается с державой
  (остаётся только береговая линия). Клик по захваченной земле выбирает державу-владельца.
- Тест карты: `python tests/test_map_geo.py`.
